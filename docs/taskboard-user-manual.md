# CJ 项目协同看板使用手册

适用对象：项目负责人、开发成员、使用任务面板整理项目工作的内部用户。

HTML 图文版：打开 `docs/taskboard-user-manual.html`。

## 0. Codex 使用标准

使用任务面板前，建议先按项目边界组织 Codex 项目。

推荐做法：

- 一个 Codex 项目只对应一个团队项目。
- 这个团队项目通常就是一个 Git 仓库里的真实项目。
- 不要在同一个 Codex 项目里长期混做多个业务项目、多个仓库或多个团队项目。

这样组织的好处：

- “生成卡片”能准确读取这个项目相关的历史对话。
- 生成出来的任务卡片更容易归到正确的团队项目。
- “提交任务卡片”时不容易把 A 项目的任务提交到 B 项目。
- 自动化执行待办队列时，Codex 只会围绕当前项目推进任务。
- 成员负载、同步日志和项目进度会更清楚。

可以简单理解为：在 Codex 里建的项目，就是任务面板里的团队项目工作区；它背后最好对应一个明确的 Git 仓库项目。

## 1. 面板状态

任务面板有两种状态。

### 本地草稿模式

当本机还没有连上公司 SQL Server 身份库时，面板会进入本地草稿模式。

可以做：

- 查看本机 Codex 项目。
- 在本地项目里创建、编辑、移动任务卡片。
- 点击“生成卡片”，把项目历史对话整理为本地任务卡片。
- 保留本地草稿，之后再提交到公司库。

不能做：

- 查看公司项目总览。
- 查看成员负载、同步日志。
- 把任务卡片提交到团队项目。

### 已连接公司库

当仓库里的 `config/sqlserver-identity.env.example` 已带有可用公司库配置，或本机存在 `.data/sqlserver-identity.env` 覆盖配置，并且数据库可访问时，面板会自动连上公司库。

可以做：

- 登记姓名和工号，之后自动进入账号状态。
- 查看公司项目进度、成员负载和同步日志。
- 创建团队项目、加入团队项目、配置项目成员。
- 把本地任务卡片提交到公司项目。
- 开启自动化，让 Codex 自动执行待办队列里的任务。
- 每半小时自动提交已绑定团队项目的新增或变更卡片。

## 2. 账号和公司库状态

点击左下角账号入口可以查看当前状态。

如果公司库可用：

1. 首次使用时填写姓名和工号。
2. 点击“登记并进入”。
3. 之后打开面板会自动恢复账号。

如果公司库不可用：

- 面板会提示“暂未连接公司数据库”。
- 用户侧不再手动填写 SQL Server 地址、端口、用户名和密码。
- 默认会从 git 仓库里的 `config/sqlserver-identity.env.example` 读取公司库连接配置。
- 如果需要覆盖仓库默认配置，再使用本机 `.data/sqlserver-identity.env`，然后重启任务面板。

切换账号会清除当前账号、记住的姓名工号，并关闭当前账号用于定时自动提交的会话。

## 3. 我的任务

“我的任务”用于处理本机项目和公司团队项目之间的同步关系。

这里会按团队项目分组展示本地项目：

- 已绑定团队项目：显示在对应团队项目分组下。
- 未认领团队项目：还没有选择提交目标。

每个本地项目行会显示：

- 项目名称和更新时间。
- 健康状态。
- 任务卡分布。
- 团队绑定。
- 提交状态。
- “提交任务卡片”和“生成卡片”操作。

## 4. 项目总览

项目总览展示公司库中已经创建且未归档的项目。

可以看到：

- 公司项目数量。
- 平均进度。
- 已完成任务数。
- 风险项目数。
- 每个项目的健康状态、整体进度、任务分布、更新时间。

项目总览支持搜索项目名称，也支持按“全部 / 正常 / 风险 / 阻塞”筛选。

注意：已归档项目不会显示在项目总览里。如果公司库中有任务卡片，但都属于已归档项目，项目总览会显示为空或没有任务数据。

## 5. 成员负载

成员负载用于查看项目成员分别承担了哪些任务。

使用方式：

1. 进入“成员负载”。
2. 选择全部项目或某一个团队项目。
3. 查看每个成员的任务数量、负载标签和状态分布。
4. 查看成员下的待办、进行中、阻塞、待验收任务。

成员负载适合判断：

- 谁的任务比较多。
- 谁有阻塞任务。
- 哪些任务还没有分配。
- 项目内任务分配是否均衡。

## 6. 生成任务卡片

“生成卡片”用于把当前本地项目相关的 Codex 对话整理成任务卡片。

点击按钮后，面板会自动使用任务面板 Skill 分析当前项目的历史对话，把明确的需求、待办、缺口或未完成事项生成本地任务卡片。

生成规则：

- 第一次点击，会处理当前还没有被整理过的项目对话。
- 下一次再点击，只处理上一次之后新增、还没有总结过的对话。
- 已经总结过的旧对话不会反复生成重复卡片。
- 已经完成、已经撤回、用户明确不要的内容，不应继续生成待办卡片。
- 生成结果只保存在本地任务面板，不会自动提交到公司库。

生成后可以手动调整：

- 修改标题和描述。
- 移动任务状态。
- 调整优先级。
- 删除不需要的卡片。

## 7. 提交任务卡片

本地生成的任务卡片需要手动提交或等待每半小时自动提交，才会上传到公司库。

手动提交步骤：

1. 确认已经连接公司库并登记账号。
2. 进入“我的任务”。
3. 找到本地项目。
4. 点击“提交任务卡片”。
5. 在弹窗里选择提交到的团队项目。
6. 确认本地项目、待提交数量、提交目标和操作人。
7. 点击“确认提交”。
8. 提交后查看同步日志和项目总览。

数据规则：

- 本地新增卡片只有提交后才进入公司库。
- 公司库已有卡片会镜像到本地显示。
- 从公司库镜像下来的卡片不会重复上传。
- 已经提交过且没有变化的本地卡片不会重复提交。
- 同一个本地项目提交时会被锁定，避免并发重复提交。
- 未连接公司库时生成的本地卡片不会丢，之后连接公司库仍可提交。

每半小时自动提交规则：

- 登记账号后，面板会把当前会话交给本地调度器。
- 本地服务运行且登录会话有效时，调度器每个整点、半点后检查所有已绑定团队项目的本地项目，每半小时最多完成一轮提交；启动后会补跑当前时段。
- 只提交新增或更新过、且还没有提交过的本地卡片。
- 没有新卡片时不会产生重复提交。
- 切换账号会关闭当前自动提交会话。

## 8. 自动化执行待办队列

项目页面右上角有“自动认领”或“无自动化”按钮。

这个功能的作用是：让 Codex 自动从当前项目的待办队列里认领任务，并按配置的间隔持续执行。它适合处理已经拆清楚、可以让 Agent 顺序推进的待办任务。

可以配置：

- 自动认领开关。
- 是否根据 Codex 额度自动启用或暂停。
- 执行间隔：5、10、15、30、60 分钟。
- 使用的模型。
- 推理强度。
- 立即执行一次。

使用建议：

- 先把需求拆成明确的待办卡片，再开启自动认领。
- 阻塞、不明确、需要人工判断的任务，不适合直接放进自动执行队列。
- 如果开启额度感知，额度不可用或未知时会暂停自动认领。
- 执行失败时，查看自动化状态和对应任务评论，再决定是否重新放回待办。

## 9. 同步日志和操作日志

同步日志用于查看本地任务卡片提交到公司库的结果。

每条记录会显示：

- 时间。
- 类型。
- 项目。
- 操作人。
- 状态。
- 新增、更新或失败结果。

如果点击提交后公司项目里没有看到任务，先查看同步日志。

## 10. 配置中心

配置中心用于维护团队项目和成员。

“我加入的项目”可以：

- 查看自己已经加入的团队项目。
- 点击“加入项目”加入已有团队项目。
- 打开某个团队项目查看任务。

“我负责的项目”可以：

- 从本机 Codex 项目创建团队项目。
- 创建后自动成为项目负责人。
- 配置项目人员。
- 查看项目。
- 删除项目。

删除项目的效果是归档公司库中的团队项目，并移除项目成员关系。它不会删除本机 Codex 项目，也不会删除公司员工源数据。

## 11. 只读项目进度页

如果只需要展示公司项目进度，可以打开：

`/?panel=database-progress`

这个页面会跳过账号登记，只显示公司项目进度总览。只读页隐藏“查看”等会进入项目详情的操作，适合放在展示屏或给只需要看进度的人使用。

## 12. 常见问题

### 为什么登录后没有数据

先确认当前未归档项目里是否有任务卡片。面板只展示未归档项目；如果任务卡片都在已归档项目里，项目总览不会显示这些任务。

### 为什么一开始是本地草稿模式

通常是仓库配置不可用、本机覆盖配置缺失，或者当前网络访问不到公司 SQL Server。确认 `config/sqlserver-identity.env.example` 或 `.data/sqlserver-identity.env` 可用并重启任务面板后，会切换到公司库模式。

### 草稿模式能不能生成卡片

可以。草稿模式生成的卡片保存在本地，连接公司库后可以手动提交到对应团队项目。

### 为什么再次点击生成卡片不会重复生成旧卡片

生成卡片会记录已经处理过的对话位置。下一次点击时，只会处理上次之后新增、还没有总结过的对话。

### 公司库和本地库会不会互相覆盖

不会。公司库任务会镜像到本地，本地新增任务必须提交才会进入公司库，镜像下来的公司任务不会重复上传。

### 为什么按钮显示已提交

当前本地项目已绑定团队项目，且没有新的待提交卡片时，按钮会显示“已提交”。如果之后修改本地任务或新增任务，按钮会重新变成“提交任务卡片”。
