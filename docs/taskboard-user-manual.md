# 任务面板使用手册

本文按当前任务面板的真实页面路径说明如何使用。任务面板的核心是：本地先创建和推进任务卡，需要团队协作时，再把本地任务提交到公司库；项目负责人可以配置团队成员，团队成员可以查看项目进度、成员负载和同步日志。

本文默认任务面板已经通过 Skill 安装完成，日常只需要让 Skill 打开任务面板。

## 1. 登录与身份

首次打开任务面板时，会进入“进入任务面板”页面。

填写：

- 姓名
- 工号

然后点击“进入任务面板”。

姓名和工号不是装饰字段，它们用于：

- 标识当前操作者。
- 记录任务、评论、提交日志是谁产生的。
- 判断“我的任务”“我加入的项目”“我负责的项目”。
- 创建团队项目时，把当前用户设为第一位项目负责人。
- 在同步日志里显示提交人姓名和工号。

进入后，左下角账号入口会显示当前姓名和工号。需要换人使用时，从这里切换账号。

## 2. 左侧导航说明

当前任务面板左侧主要入口如下：

| 入口 | 用途 |
| --- | --- |
| 议题 | 当前项目的议题看板入口 |
| 项目总览 | 查看团队项目整体进度 |
| 我的任务 | 查看本地项目、生成本地任务卡、提交任务卡片 |
| 配置中心 | 创建团队项目、加入团队项目、配置项目成员 |
| 同步日志 | 查看任务卡提交到公司库的记录 |
| 项目列表 | 直接进入某个 Codex 项目的议题看板 |

首页顶部会显示当前模式：

- 本地草稿模式：本地可以创建和维护任务，未提交到公司库。
- 已连接公司库：可以做团队项目、成员配置、提交任务和查看同步记录。

## 3. 本地任务怎么做

本地任务是在自己设备上先推进的任务卡。

路径：

1. 左侧点击“我的任务”。
2. 在“我的项目进度”里找到本地项目。
3. 点击项目名称进入该项目。
4. 在“议题看板”里创建、移动和维护任务卡。

项目行会显示：

- 项目名称
- 健康状态
- 任务卡分布
- 团队绑定
- 提交状态
- 操作

任务卡常用字段包括：

- 标题
- 描述
- 状态
- 优先级
- 标签
- 负责人
- 到期日期
- 重复规则
- Git 分支或 worktree
- 评论和附件
- 父子任务、阻塞关系、相关任务

推荐状态流转：

1. 待规划：先放着，以后再处理。
2. 待办：已经确定要做。
3. 进行中：正在处理。
4. 待验收：已经处理完，等待确认。
5. 已完成：确认完成。

如果任务卡住，移动到“阻塞”，并在评论里写清楚原因。

## 4. “我的任务”里的两个关键操作

在“我的任务”的项目行右侧，有两个关键操作：

- 提交任务卡片
- 生成卡片

这两个按钮含义不同。

### 提交任务卡片

“提交任务卡片”是把当前本地项目的任务卡提交到团队项目，也就是公司库。

路径：

1. 左侧点击“我的任务”。
2. 找到本地项目。
3. 确认“团队绑定”列已经显示绑定的团队项目。
4. 点击“提交任务卡片”。

提交后：

- 新任务会导入团队项目。
- 已存在的任务会更新。
- 重复任务会被去重。
- 同步日志会记录提交结果。
- 团队进度以本次提交后的数据为准。

如果提交失败，本地草稿会保留。修复问题后可以再次提交。

“提交状态”列显示的是最近一次提交结果：

| 状态 | 含义 |
| --- | --- |
| 未提交 | 这个本地项目还没有提交记录 |
| 成功 + 时间 | 最近一次提交成功，时间为提交发生时间 |
| 提交失败 | 最近一次提交失败，鼠标悬停可查看失败原因 |

右侧“操作”列里的按钮是另一回事：

| 按钮文字 | 含义 |
| --- | --- |
| 提交任务卡片 | 当前项目已绑定团队项目，并且可以发起提交 |
| 提交中 | 正在上传任务卡，按钮暂时不可重复点击 |
| 已提交 | 最近一次成功提交时间不早于本地任务最新更新时间，当前没有新的本地变更需要提交 |

因此，看到“成功 + 时间”不一定代表按钮也显示“已提交”。如果你后来又改了本地任务卡，提交状态列仍会显示上一次成功时间，但按钮会重新变成“提交任务卡片”，提示可以再次同步。

### 生成卡片

“生成卡片”不是提交团队，也不是随便生成空任务。它会整理当前本地项目相关的 Codex 历史对话，把其中明确的需求、进展和待办拆成本地任务卡。

路径：

1. 左侧点击“我的任务”。
2. 找到本地项目。
3. 点击“生成卡片”。

生成卡片会做的事：

- 读取当前项目工作区下新增的 Codex 本地会话。
- 跳过已经整理过的旧内容，避免重复生成。
- 忽略没有明确任务的对话。
- 一个对话可以拆成多张任务卡。
- 生成结果只进入本地任务卡，不会直接上传团队项目。

生成成功后，会提示“已生成 N 张本地任务卡片”。如果没有新增可整理内容，会提示没有发现新的未处理对话。

以前也可以直接通过 Skill 让 Agent 把对话拆成任务卡；这个方式没有废弃。“生成卡片”只是把同类能力做成了面板按钮，适合不想再单独对 Agent 下指令时使用。

## 5. 创建团队项目

创建团队项目在“配置中心”，不在“我的任务”。

路径：

1. 左侧点击“配置中心”。
2. 找到“我负责的项目”。
3. 点击“创建团队项目”。
4. 在弹窗里选择一个 Codex 项目。
5. 点击“确认创建”。

创建成功后：

- 当前用户成为第一位项目负责人。
- 本地项目会绑定到这个团队项目。
- 任务卡仍保存在本地。
- 需要团队看到任务时，再去“我的任务”点击“提交任务卡片”。

也就是说，“创建团队项目”只建立团队项目和负责人关系，不等于提交任务。

## 6. 配置项目成员

配置成员也在“配置中心”。

路径：

1. 左侧点击“配置中心”。
2. 在“我负责的项目”中找到团队项目。
3. 点击“配置人员”。
4. 在“选择开发成员”中选择人员。
5. 点击“添加成员”。

成员列表中会区分：

- 项目负责人：创建团队项目的人，固定显示为项目负责人。
- 开发成员：负责人添加进来的项目成员，可移除。

配置成员后，团队成员才能围绕同一个团队项目查看和提交任务，成员负载也能按成员统计。

## 7. 加入团队项目

加入项目也在“配置中心”。

路径：

1. 左侧点击“配置中心”。
2. 找到“我加入的项目”。
3. 点击“加入项目”。
4. 选择一个已创建的团队项目。
5. 点击“确认加入”。

加入后，“我加入的项目”会显示：

- 项目名称
- 项目负责人
- 我的角色：项目负责人或开发人员

加入后可以查看项目任务，并参与后续本地维护和提交。

## 8. 查看团队成员进度

成员负载不是左侧一级入口。它从“项目总览”的具体团队项目进入。

路径：

1. 左侧点击“项目总览”。
2. 在“项目进度”表格里点击某个团队项目。
3. 进入该项目详情后查看“成员负载”。

成员负载会按成员展示：

- 总任务数
- 待办
- 进行中
- 阻塞
- 待验收

每个成员右侧会按状态列出任务。项目负责人可以用它判断：

- 谁任务最多。
- 谁正在推进。
- 哪些任务阻塞。
- 哪些任务等待验收。

## 9. 查看项目总览

路径：

1. 左侧点击“项目总览”。
2. 查看顶部统计和“项目进度”表格。

项目总览会展示：

- 健康项目
- 风险项目
- 阻塞任务
- 待验收
- Codex 执行中
- 本周到期

项目进度表格会展示：

- 项目
- 健康状态
- 进度
- 任务卡分布

健康状态大致表示：

- 正常：推进平稳。
- 有风险：存在待验收、未完成或需要关注的任务。
- 阻塞：项目中存在阻塞任务。

点击团队项目后，可以继续查看成员负载等项目内详情。

## 10. 查看同步日志

同步日志用于确认谁把哪些任务提交到了公司库。

路径：

1. 左侧点击“同步日志”。
2. 查看“提交记录”。

同步日志显示：

- 时间
- 项目
- 提交人
- 结果
- 任务数量
- 详情

详情里会展示新增和更新数量。失败时会显示失败原因。

你能看到：

- 自己的提交。
- 你所属项目里其他成员提交到公司库的记录。

当团队成员说“我已经提交了”，可以在这里确认是否真的成功、提交了多少任务、有没有失败。

## 11. 关注事项和 Codex 执行中心

“关注事项”用于聚合需要处理的问题，例如：

- 自动化失败
- 阻塞任务
- 项目映射风险

“Codex 执行中心”用于查看 Codex 自动化相关状态，例如：

- Codex 正在做什么。
- 当前执行卡在哪里。
- 是否等待人工确认。
- 是否有失败记录。

这些入口主要用于项目负责人快速判断哪里需要人工介入。

## 12. 评论、附件和任务关系

任务详情页支持协作记录。

评论适合记录：

- 处理进展
- 验证结果
- 阻塞原因
- 评审意见
- 交接说明

附件适合放：

- 截图
- 文档
- 设计稿
- 错误日志
- 对照材料

任务关系适合表达：

- 父子拆分
- 阻塞关系
- 相关任务

推荐做法：

- 大需求先拆父任务和子任务。
- 遇到依赖，用阻塞关系表达。
- 待验收前，把关键验证结果写进评论。

## 13. Skill 和面板按钮的关系

任务面板 Skill 仍然可以直接使用。

两种方式都有效：

- 直接让 Agent 使用 Skill：适合在对话中让 Agent 拆任务、创建任务卡、推进任务状态。
- 点击面板按钮“生成卡片”：适合把当前项目的历史 Codex 对话批量整理成本地任务卡。

它们不是替代关系。按钮是新增入口，Skill 方式没有废弃。

推荐用法：

- 对当前正在聊的需求，可以直接让 Agent 用 Skill 拆成任务卡。
- 对过去一段时间积累的项目对话，可以在“我的任务”里点“生成卡片”批量整理。
- 生成后先在本地检查任务卡，再决定是否点击“提交任务卡片”上传团队。

## 14. 推荐团队工作流

项目负责人：

1. 首次进入面板，填写姓名和工号。
2. 在“配置中心”创建团队项目。
3. 在“配置中心”配置开发成员。
4. 在本地项目中创建或生成任务卡。
5. 在“我的任务”点击“提交任务卡片”上传到公司库。
6. 在“项目总览”查看团队项目进度。
7. 点击项目进入成员负载，监控成员推进情况。
8. 在“同步日志”确认成员提交记录。

开发成员：

1. 首次进入面板，填写姓名和工号。
2. 在“配置中心”加入团队项目。
3. 在本地维护自己的任务卡。
4. 需要同步团队时，在“我的任务”点击“提交任务卡片”。
5. 在“同步日志”确认提交是否成功。

Agent：

1. 使用 Skill 读取项目和任务卡。
2. 根据需求创建或更新任务。
3. 开始处理前移动到进行中。
4. 完成后写评论说明改动和验证。
5. 移动到待验收，等待用户确认。

## 15. 常见问题

### 创建团队项目后，任务会自动上传吗？

不会。创建团队项目只建立团队项目和负责人关系。任务仍在本地，需要到“我的任务”点击“提交任务卡片”。

### “生成卡片”和“提交任务卡片”有什么区别？

“生成卡片”是把 Codex 历史对话整理成本地任务卡。“提交任务卡片”是把本地任务卡上传到公司库。一个是生成本地任务，一个是同步团队数据。

### 以前让 Skill 直接拆任务卡的方式还能用吗？

能用。面板里的“生成卡片”只是新增按钮入口，不废弃 Skill 方式。

### 成员负载在哪里？

左侧点击“项目总览”，再点击具体团队项目，进入项目详情后查看“成员负载”。

### 创建项目和配置人员在哪里？

都在左侧“配置中心”。“我负责的项目”里创建团队项目和配置人员；“我加入的项目”里加入已有团队项目。

### 怎么知道成员有没有提交？

左侧点击“同步日志”，查看项目、提交人、结果和任务数量。

### 提交失败会丢本地任务吗？

不会。本地草稿会保留，修复问题后可以再次提交。
